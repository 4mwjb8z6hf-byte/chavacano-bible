# Chavacano Bible — Offline-ready PWA v3

This app is an independent reading interface for the Chavacano New Testament (cbkNT), translated by Wycliffe Bible Translators, Inc. (1981).

The GitHub Actions workflow downloads the official eBible.org zipped HTML distribution at build time and publishes the chapter files with the app. The app can then cache the local chapter files for offline use.

License/source information must remain with the translation. The translation is not sold and the Scripture words/punctuation are not changed.
