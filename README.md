# Chavacano Bible PWA v2

A polished iPad/iPhone-first Progressive Web App.

## Features
- All 27 New Testament books and chapter navigation
- Displays the exact licensed Chavacano chapter from eBible.org
- Previous/Next navigation
- Saved chapter references
- Local study notes
- Dark mode
- Standalone Home Screen experience
- Works across iPhone, iPad, Android, Windows and Mac

## Install on iPad
1. Host this folder on any HTTPS static host.
2. Open the HTTPS address in Safari.
3. Tap Share -> Add to Home Screen.
4. Launch "Chavacano Bible" from the Home Screen.

## Important
The Scripture pane loads from eBible.org, so this v2 requires internet for the Bible text. The app shell, notes and saved references are local.
